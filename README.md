# xue

study code

## Install

```
make build
```

Requires Go 1.22+ and [Claude CLI](https://docs.anthropic.com/en/docs/claude-cli) installed locally.

## Usage

```
xue                              # launch TUI
```

## TUI keys

| Key | Action |
|-----|--------|
| `w` | new workspace |
| `a` | add source repo |
| `n` | ask question |
| `s` | workspace settings |
| `enter` | open thread chain |
| `f` | follow-up question |
| `d` | delete |
| `tab` | switch panel |
| `q` | quit |

## Test

```
make test
```
